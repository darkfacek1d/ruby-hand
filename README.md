## 💡 What is Ruby Hand?

Ruby Hand is a desktop app that squeezes more FPS out of your PC. It scans your hardware, recommends in-game graphics settings for popular titles, kills background bloat before you launch, and estimates the FPS you should expect.

No overlays. No subscriptions. Just a clean black interface that does the boring stuff for you.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔍 **Hardware Scan** | Detects CPU, GPU, RAM, OS, motherboard, and disks |
| 🎮 **Game Presets** | Recommended settings for CS2, Dota 2, Rust, Fortnite, Apex, Valorant |
| ⚡ **One-Click Boost** | Kills heavy background processes + switches to High Performance power plan |
| 📊 **FPS Estimator** | Predicts FPS range and shows your bottleneck (CPU / GPU / Balanced) |
| 🌡️ **Temp Monitor** | Live CPU/GPU temperature updates every 3 seconds |
| 🧹 **RAM Cleaner** | Clears standby memory list |
| 🛡️ **Safe Process Killer** | Whitelist protects critical Windows processes |
| 💎 **Liquid Glass UI** | Custom frameless window, black theme, ruby gradients |

## 🚀 Quick Start

### Requirements

- Windows 10 / 11 (x64)
- Node.js 20+

### Development

```bash
# 1. Clone
git clone https://github.com/darkfacek1d/ruby-hand.git
cd ruby-hand

# 2. Install dependencies
npm install

# 3. Run in dev mode
npm run dev
